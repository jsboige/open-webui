# TP Prompt Engineering — Guide de l'étudiant

## Objectif
Apprendre à rédiger des prompts efficaces pour les LLMs, des techniques de base aux approches avancées.

## Prérequis
- Accès à la plateforme Open WebUI
- Aucune compétence technique requise (TP accessible à tous)

## Comment démarrer
1. Connectez-vous à Open WebUI
2. Sélectionnez le modèle **TP Prompt Engineering** dans la liste
3. Envoyez un message de bienvenue (ex: "Bonjour, je commence le TP")
4. Le tuteur vous guidera automatiquement à travers les modules

## Programme (5 modules progressifs)

### Module 1 — Fondamentaux : Rôles et Clarté (⭐)
- Comprendre les rôles système/utilisateur/assistant
- Rédiger des prompts clairs et spécifiques
- **Défi** : Résumer un article de 3 façons différentes

### Module 2 — Techniques de base : Zero-shot et Few-shot (⭐⭐)
- Zero-shot : donner une instruction sans exemple
- Few-shot : fournir des exemples pour guider le modèle
- **Défi** : Classifier des avis clients avec et sans exemples

### Module 3 — Raisonnement structuré : Chain-of-Thought (⭐⭐⭐)
- Forcer le raisonnement étape par étape
- Utiliser "Réfléchis étape par étape" et ses variantes
- **Défi** : Résoudre un problème de logique avec CoT

### Module 4 — Extraction structurée : JSON et formats (⭐⭐⭐)
- Demander des sorties en JSON, tableaux, listes
- Contraindre le format de réponse
- **Défi** : Extraire des informations structurées d'un texte

### Module 5 — Prompts avancés : Meta-prompting et Chaining (⭐⭐⭐⭐)
- Meta-prompting : demander au LLM d'écrire un prompt
- Prompt chaining : enchaîner plusieurs prompts
- **Défi** : Créer un pipeline de prompts pour analyser un document

## Évaluation
- Chaque défi est noté sur 10 par le tuteur
- Critères : clarté, spécificité, efficacité du prompt, qualité du résultat
- Score total : /50

## Commandes utiles
- Tapez **"aide"** ou **"indice"** si vous bloquez
- Tapez **"solution"** pour voir la réponse complète avec explications
- Tapez **"module suivant"** pour passer au module suivant

## Durée estimée
- 2 à 3 heures pour les 5 modules
- Possibilité de faire 1-2 modules par session
